Сайт моих игр
мини-игрки для развлечения — арифметика, ножницы-бумага, переверни текст, генератор цветов, викторина и угадывание числа. 
Сайт-визитка с красивой анимацией и карточками игр.

Как запустить:
Скачай репозиторий.
Открой папку frontend-main.
Открой index.html в любом браузере.


Технологии:
HTML5
SCSS
Google Fonts (Montserrat)
